# BadTimeSignature.date_signed 有时是 int，不是 datetime

复现环境：Windows + Python 3.13 + pytest

---

我们用 `TimestampSigner` 校验回调地址里带回来的令牌。签名不匹配时它抛
`BadTimeSignature`，我们把异常上的 `date_signed` 直接写进审计日志，也格式化后展示给用户。

问题是同一个属性有两种类型：

```python
from itsdangerous import BadTimeSignature, TimestampSigner

signer = TimestampSigner("secret-key")
signed = signer.sign("my string").replace(b"my", b"other", 1)  # 破坏负载，签名因此失效

try:
    signer.unsign(signed)
except BadTimeSignature as exc:
    print(repr(exc.date_signed))
```

实际输出是 `1789562900`——一个 int。而超时场景抛出的 `SignatureExpired`
（同样是 `BadTimeSignature` 的子类）给的却是带时区的 `datetime`。

我们捕获的是基类 `BadTimeSignature`，所以同一个 except 分支里既要处理 int 又要处理
`datetime`，还得再判 `None`，非常难用。`date_signed` 的文档说它暴露的是签名时间，
那就应该始终是 `datetime`；反正不要出现"有时 int"。

约束：
- 时间戳缺失、或时间戳无法解析时，`date_signed` 保持为 `None`（现状如此，别改坏）；
- 只改源码，不要动测试与测试配置。
